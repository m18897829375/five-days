## Codebase Patterns
- Backend: FastAPI + SQLAlchemy async (asyncpg) + PostgreSQL + pgvector
- Frontend: React 19 + TypeScript + TailwindCSS 4 + Vite
- Docker services in `infra/docker-compose.yml` (postgres, redis, minio, backend, frontend, embed)
- Backend config in `backend/app/core/config.py` — Pydantic Settings with env vars
- EMBED_BASE_URL defaults to `http://localhost:8001`, EMBED_DIMENSIONS=1024
- embedder.py: tries embed server first, falls back to keyword pseudo-vectors
- BGE-M3 model via sentence-transformers in Docker container
- SQLAlchemy `select(Entity)` returns `Result[tuple[Entity]]`; use `.scalars().all()` to get `list[Entity]` for type-safe attribute access
- HNSW indexes via `op.execute("CREATE INDEX ... ON ... USING hnsw (...) WITH (...)"` in Alembic — cannot use SQLAlchemy ORM declarations
