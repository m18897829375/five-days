## Codebase Patterns
- Backend: FastAPI + SQLAlchemy async (asyncpg) + PostgreSQL + pgvector
- Frontend: React 19 + TypeScript + TailwindCSS 4 + Vite
- Database models in `backend/app/models/` using SQLAlchemy declarative base with BaseMixin (id, created_at, updated_at)
- API routers in `backend/app/api/` with FastAPI APIRouter, prefix `/api/...`
- Alembic migrations in `backend/alembic/versions/`
- Frontend state: localStorage for conversations/messages persistence
- Vite proxy forwards `/api` to backend port 8000
- Backend lint: ruff with B008 ignored (FastAPI Depends pattern)
- Frontend: TypeScript strict mode, `tsc --noEmit` for typecheck
- Dark theme CSS custom properties in `src/index.css`
- Ralph script at `scripts/ralph/ralph.sh` reads `prd.json` from same directory
- Scraper pattern: Playwright Chromium with stealth scripts, TokenBucket rate limiter, RobotsChecker for robots.txt compliance, exponential backoff retry
- `app/utils/` for shared utilities (rate_limiter, robots_checker)
- Scrapers in `app/services/` with best-effort fallback to mock data in chat_service
- mcp-bosszp vendor at `backend/vendor/mcp-bosszp/` — Boss直聘 official API via MCP
- MCP subprocess managed by `BossMCPClient` with HTTP streamable-http transport (JSON-RPC 2.0)
- Cookie persistence to `backend/vendor/mcp-bosszp/cookie.json` — auto-loaded on startup
- Login state machine: UNKNOWN → LOGGING_IN → WAITING_FOR_SCAN → LOGGED_IN / EXPIRED
