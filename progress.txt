## Codebase Patterns
- **Prisma 7**: `url`/`directUrl` 不再在 schema.prisma 中定义，必须在 `prisma.config.ts` 中使用 `defineConfig({ datasource: { url: env('DATABASE_URL') } })`。Schema 中 datasource 块只保留 `provider = "postgresql"`。
- **Prisma 7 Enum/Model 命名**: Prisma 不允许 enum 和 model 同名。之前 `QuizStep` 同时是 enum 和 model 导致验证错误。解决方案：enum 命名为 `QuizStepEnum`，model 保持 `QuizStep`。
- **Prisma 7 Client**: `@prisma/client` 导入仍可用。`prisma generate` 默认输出到 `node_modules/@prisma/client`，generator 不需要 `output` 配置。
- **Prisma 7 auto-loads .env**: `prisma.config.ts` 会自动加载项目根目录的 `.env` 文件，无需手动 `dotenv/config`。
- **Supabase + Prisma 7**: `directUrl` 概念在 Prisma 7 的 `prisma.config.ts` 中不存在。`prisma db push` 使用 `datasource.url`。对 Supabase PgBouncer，`DATABASE_URL` 应指向直连端口 5432（DDL 需要），运行时客户端可用连接池端口 6543。
- **TypeScript 6 + moduleResolution bundler**: `process.env` 需要 `@types/node`。tsconfig 中添加 `"types": ["node"]` 以引入 Node.js 全局类型。
- **tsconfig for Next.js 16**: compilerOptions 使用 `module: "esnext"` + `moduleResolution: "bundler"`，包含 `plugins: [{ "name": "next" }]`。
- **Zod 分层模式**: schemas.ts 定义 Zod 验证规则，types.ts 通过 `import type { z }` + `z.infer` 纯类型层导出。import type 避免运行时代码引入。
- **ApiResponse 泛型**: Zod schema 做函数封装 `(dataSchema) => z.object(...)`，TypeScript 类型用纯泛型 `ApiResponse<T>` 定义。
